Can we reproduce published results for 3D vision models?

Plumbline studies depth and camera-pose evaluation. It records the settings used in each paper, runs the public model, and reports whether the new result matches the published result.

A result counts as reproduced when we read the target value in the paper, run the full evaluation, and get a value within the stated tolerance. Extra metrics from the same run do not increase the count.

01 / research question

A published number depends on many choices.

The result depends on the checkpoint, image size, dataset records, crop, valid mask, alignment, aggregation, and metric code. Papers do not always state all of these choices.

Research aim

We want to separate differences between models from differences between evaluation methods.

Plumbline saves each evaluation method as a versioned configuration. Models share the same metric code where possible. Results that do not match the paper remain in the record.

02 / findings so far

What we have learned.

A

Small changes can change the score.

The median estimator, alignment method, crop, frame set, and aggregation rule can determine whether the public checkpoint matches the paper.

B

We report results that do not match.

Some public checkpoints still produce a different result after we check the implementation. We publish these differences and their likely causes.

C

Camera tracking needs more than one score.

ATE and pose AUC do not show every problem. They can hide jitter, short failures, recovery, and missing frames. We now add blinded comparisons of complete trajectories.

03 / method

How we check each result.

  1. 01

    Read the paper

    Record the table, row, column, metric, target value, and tolerance from the PDF.

  2. 02

    Record the evaluation settings

    Save the checkpoint, dataset records, preprocessing, alignment, masks, metric code, and aggregation rule in YAML.

  3. 03

    Run every required sample

    Save raw predictions before alignment and record the software and hardware environment. Reject incomplete runs.

  4. 04

    Compare the values

    Mark a result as reproduced only when the full run is within tolerance. Report other results in separate groups.

06 / reproduce & cite

Run the same evaluation.

You can run a saved evaluation, read its exact settings, or submit a correction. Most model runs require a CUDA GPU. Reading the results and settings does not.

$ pip install plumbline-bench
$ plumbline reproduce da-v2-large-nyuv2

→ AbsRel  0.0428
→ paper   0.0420
→ status  match

How to cite this work

Cite the version of Plumbline that you used. Also cite each model and dataset included in your results.
